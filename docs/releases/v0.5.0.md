`manage_roles` に、AI自身が使い方を確認するための読み取り専用 `help` アクションを追加しました。PR #21の機能追加版です。

## 使い方

```json
{ "action": "help" }
```

次の4項目の違いを、短い説明とレビュー役の例で案内します。

- **ロールの `description`**：親AIが「いつこの役割に任せるか」を判断する説明。子への指示ではありません。
- **ロールの `instructions`**：子AIの進め方・制約・報告方法。上位指示や実行権限を上書きするものではありません。
- **`delegate.prompt`**：今回の具体的な仕事・対象・必要な文脈・完了条件。
- **`delegate.description`**：今回の仕事の短い表示名。保存するロールの説明とは別です。

既存ロールの再利用、各アクションの引数、作成・更新・削除の構文例、`list/get → preview → apply → list → 必要なら apply_current → 次のツール境界で delegate` を案内します。例の版番号・planId・会話のrevisionは、実際の応答で置き換える必要があります。helpを読んでも例は実行されません。

## 安全性と範囲

- helpも既存の**許可スイッチ・liveな親限定・子の拒否・古いツール参照の拒否・キャンセル**を維持します。read-onlyの親は参照できますが、変更権限を得るものではありません。
- 応答は固定の説明だけです。現在の設定やロール内容を返さず、**設定保存・preview plan作成・履歴／モデル取得・子の起動を行いません**。認可のための設定参照は行います。
- `help` にtopic・検索・ページ分割などは追加していません。通常のツール説明にはhelpへの案内と、親向け説明／子向け指示の短い補足を追加しています。
- 保存と現在会話への反映、子の起動は引き続き別操作です。`readOnly: true` と文章で「変更しない」と書くことも区別します。
