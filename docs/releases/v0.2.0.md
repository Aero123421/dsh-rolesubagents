ロールの実行先として、DSH内部のサブエージェントに加えて **Codex CLI・Claude Code・Antigravity CLI（agy）・OpenCode** を選べるようになりました。

- ロールごとに実行先、モデル、推論の強さ、権限、タイムアウトを設定できます。OpenCodeではプロバイダーも選べます。
- 同じCLIを使う複数のロールに、異なるモデルや指示を設定できます。
- 親は従来どおり `delegate` を使い、完了通知で結果を受け取ります。
- 接続テストと、英語・日本語の設定画面を追加しました。
- CLIごとの差分をアダプターに分離し、起動・停止・結果返却の共通基盤を追加しました。

レビューで確認された権限の制限漏れ、アンロード中の起動、残存子プロセスによる終了待ち、JSON内のパス処理、Node 24での検証スクリプトの再帰を修正しました。公開前の追加検証で見つかった `.git` 内のリンクによる範囲外書き込みも修正しています。

外部CLIのロールは一回の依頼で完結し、開始後の `send_message` は使えません。Claude Codeの制限付きプリセットはシェルを使わず、OpenCodeなどのファイル編集プリセットでは安全に範囲を確認できないディレクトリの起動を拒否します。これらはCLIのツール権限と起動前検査による制限で、OSサンドボックスと同じ保証ではありません。ハードリンクや実行中の外部からのファイル構造変更は検査対象外です。詳細はREADMEを参照してください。

導入はDSH Webの **Plugins → Add plugin**、または次のコマンドで行えます。

```sh
dsh plugin --profile web add github:Aero123421/dsh-rolesubagents#v0.2.0
```

更新後はDSHを再起動し、新しいセッションで設定してください。CLIの実行ファイルと認証はDSHホスト側に必要です。既存の0.1.x設定は引き続き読み込めます。

配布物 `dsh-rolesubagents-0.2.0.tgz` と `SHA256SUMS` を添付しています。GitHub Releaseの公開時にもlint・型検査・通常テスト・配布ビルドの一致を確認します。実CLIの検証はローカルのテスト用モデル応答を使い、実モデルの応答品質やWindows実機の動作は対象にしていません。
