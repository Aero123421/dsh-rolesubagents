設定画面の保存バーが、最後の行と接続テストの失敗文を隠さないようにしました。日本語の表示には [dsh-japanese](https://github.com/Aero123421/dsh-japanese) が必要であることも明記しています。

- 保存バーはこれまでどおり画面の下に固定します。DSH Web はプラグイン設定を `overflow: auto` の親でスクロールし、その親には下の余白があります。`position: sticky; bottom: 0` はその余白の内側に張り付くため、最後の行がバーの裏と余白にはみ出していました。スクロール領域の `scroll-padding-bottom` を、バーの高さとその余白の合計にし、接続テストの結果は `scrollIntoView({ block: 'nearest' })` で見える位置まで動かします。
- 日本語の表示には dsh-japanese が必要です。このプラグインは `ja` を登録しません。dsh-japanese を入れ、言語を日本語にしてください。辞書はこれまでどおりこのプラグインが持ち、DSH の現在の言語が `ja` のときだけ日本語になります。dsh-japanese が無いときと、中文（`zh-CN`）のときは英語になり、キー名はそのまま出ません。
- 保存済み設定を修復したときの説明も、同じ辞書の文を出します。

この版では Codex CLI、Claude Code、Antigravity CLI（agy）、OpenCode の実バイナリは再確認していません。0.2.0 で確認した CLI の挙動はそのままです。
