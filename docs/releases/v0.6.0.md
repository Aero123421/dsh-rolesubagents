# v0.6.0 — clearer delegation and results

A simpler activity-first catalog, usable external results, and one-shot delegation settings without persistent role edits.

## English

- **Compact catalog:** click/keyboard-only opening, explicit direct-child/sibling scope, current/attention entries first and completed/cancelled history collapsed. Ordinary lists/buttons, opaque theme backgrounds and mobile sizing replace a dense all-history view. Role metadata survives reopen; per-parent external refreshes distinguish fresh, stale, missing and unavailable data. Stopped/unknown never means idle or successful.
- **External results:** a nonmodal inspector keeps the parent chat usable. Copy and readable/raw views use plain text, not Markdown/HTML rendering; parent navigation leads to the returned answer. Execution details start collapsed. Startup is only a receipt; requested model/effort is not confirmation of the actual route used.
- **One-shot settings:** DSH spawn roles accept `provider` and `model` together plus optional `effort`. A replacement pair clears old effort; effort alone requires a configured role model. Native route validation applies. Fork roles (including task-only) and CLI roles reject route/effort overrides. `readOnly: true` only strengthens the run; `false` and unsupported CLI read-only presets are refused. No saved role or session catalog is changed.
- **Read-only startup:** child management restrictions are installed only for a visible inherited management tool. An absent tool no longer breaks child initialization; child administration remains denied by live checks/guards.
- **Model refresh:** explicit Web refresh supports Codex, Antigravity and OpenCode, with validated candidates, provenance/timestamps and retained last-good lists. Claude aliases are static; Grok/Pi have no live model discovery. No automatic CLI upgrading, login or inference is added.

### Limits

External metadata is supplementary: at most **100 records across the Host, 7 days, 16,384 UTF-16 code units per result preview**. Copy copies only the retained preview. Persistence failure is labeled non-durable; missing/expired/evicted records cannot be reconstructed here. There is no live stdout/tool stream, CLI follow-up chat, new stop button or old-history recovery. Use `interrupt_agent` for cancellation; the direct parent remains the final-result destination. Existing CLI permissions, confinement caveats and restart/delivery limits remain unchanged.

Optional catalog integration still depends on supported public DSH slot/service contracts; it is not compatibility certification for every DSH version. No settings migration is required for these additions. Existing session snapshots remain unchanged unless explicitly refreshed through authorized management.

## 日本語

- **一覧を簡潔に：** クリック・キーボードだけで開き、直下の子／兄弟の対象を明示します。稼働中・要確認を先に、完了・キャンセルの履歴は折りたたみます。通常のリストとボタン、不透明な背景、モバイル対応を使います。ロール情報は開き直しても保持し、外部状態は親ごとに更新・更新停止・記録なしを区別します。不明や停止を成功扱いにしません。
- **外部結果：** 親チャットを操作できる非モーダルパネルで、結果のコピー・読みやすい表示／原文表示・親への移動を提供します。本文はプレーンテキストで、Markdown／HTMLは描画しません。実行情報は折りたたみます。起動通知は最終結果でも、実効モデル・推論設定の確認でもありません。
- **今回だけの設定：** DSHの新規ロールは `provider`＋`model` と任意の `effort` に対応します。組の置き換えで元の推論設定を解除し、推論設定だけならロールのモデル指定が必要です。fork（タスクのみも含む）とCLIの経路上書きは拒否します。`readOnly: true` は強化のみで、`false` や未対応CLIは拒否します。保存設定・現在一覧は変更しません。
- **安全性とモデル候補：** 継承された管理ツールがない子の起動失敗を修正し、子の管理権限禁止は維持します。明示的なモデル更新はCodex・Antigravity・OpenCodeのみで、検証した候補と最終成功一覧を保持します。Claudeは静的一覧、Grok/Piはライブ取得未対応です。CLIの自動アップグレードはしません。

外部記録は **Host全体100件・7日間・結果16,384 UTF-16コード単位まで**です。コピーも保持した範囲のみです。永続化失敗・古い記録・省略を明示し、ライブ出力、追加会話、停止ボタン、過去履歴の復元は提供しません。停止は `interrupt_agent`、最終結果は直接の親チャットを使います。既存のCLI権限・閉じ込め・再起動時の制限は変わりません。設定移行は不要で、既存セッションの一覧は自動更新しません。

## Validation — 2026-10-29

- Lint, Host/client/test TypeScript and build passed; **1,582 tests across 53 files passed**.
- Installed DSH **0.2.1-rc.2** native delegation checks passed, including one-shot model/effort resolution, unchanged parent settings, read-only write refusal and pre-activation failures. No paid model inference was required.
- Installed-Host management checks: **23 passed**, including both inherited and isolated child tool scopes. Strict read-only remains fail-closed.
- Connection/Gateway checks passed for authenticated, parent-scoped external results and the shipping bundled artifact, including literal signal argument preservation.
- Isolated Chromium **149** component checks: **30 passed**, including dark/light, desktop and 320/390px mobile, touch, keyboard, opaque backgrounds, safe text, focus recovery and independent stale state. Browser sandbox was unavailable in this environment; Chromium used an isolated disposable profile with the explicit `--no-sandbox` option.
- Deployed GUI: **31 catalog checks passed** on the existing service after restart, with desktop and 320/390px mobile screenshots directly inspected. Current/attention appeared above collapsed history; opacity, compact trigger, click/keyboard dismissal and viewport bounds were checked without page-local CSS overrides. Authenticated root/API and exact served client bundle matched the prepared build.
- Independent static security review found no critical/high blockers in these changes. This is not a guarantee for every Host/CLI version; live CLI/model backends were not comprehensively requalified. Screen-reader and all-theme deployed-GUI certification remain outside this validation.

Reproduce with `pnpm check`, `pnpm check:delegation`, `pnpm check:management`, `pnpm check:probe`, and `pnpm check:catalog-browser` using the documented installed-Host/browser prerequisites. Private live-GUI captures and credentials are not shipped.
